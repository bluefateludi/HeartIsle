# 心屿维护者主线

记录日期为 2026-11-15。本目录记录开发者和维护者长期推进的工作。

## 持续建设有价值的内容库

持续收集、整理、发布和维护自己认可的内容，帮助读者平复情绪、理解自己、拓展观念和改善决策。内容选择以维护者的价值判断为依据，逐步积累。

### 收录范围

- 心理学视频，以及能够启发观念和决策的视频。
- 正向支持、帮助人们平复情绪的文章。
- 书籍及相关阅读笔记，例如《原则》。
- TED 演讲。

### 发布方式

结合站内发布与原内容推荐，让读者既能阅读站内内容，也能找到原始来源。

- 站内发布文章、阅读笔记、视频解读，以及适合站内阅读且具备发布权限的内容。
- 原内容推荐保留来源链接，可附维护者的推荐理由、核心观点和个人理解。
- TED 演讲先采用标题、封面和原视频链接的形式，点击后前往原内容，推荐理由按需补充。

### 长期维护工作

1. 收集候选内容，挑选值得收录的材料。
2. 记录标题、作者或讲者、内容形式、主题和原始来源，按需补充推荐理由。
3. 决定每条内容的呈现方式，整理后发布到网站。
4. 持续补充内容，检查失效链接，修订介绍和理解。
