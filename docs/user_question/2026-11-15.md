# 用户实际问题记录

记录日期为 2026-11-15。以下保留用户原话，并整理对应的问题与诉求。

## 1. 以八天为周期的长期作息安排

### 用户原话

> 这个华子，我的生活基本上8天一个轮回，这八天每天都不同的休息时间，可以有那种扫描作息时间，然后把这八天当作一个sop去安排。这八天虽然休息时间分布不均，但是每一轮休息时间基本固定，对于adhd来讲规律点应该比较好吧，就这像这种长期一点的adhd日程安排也可以实现吗？

### 问题与诉求

- 生活以八天为一个循环，每天的休息时间不同，每轮对应的休息时间基本固定。
- 希望能够扫描、识别作息时间，将八天周期保存为可重复使用的 SOP，并据此安排长期日程。
- 用户想了解这样的周期安排能否帮助自己维持规律，以及软件能否支持。

## 2. 长期任务难以持续推进，需要记住进度

### 用户原话

> 作为拖延症感觉对我最难完成的其实是长期任务，短期的考试或者工作都可以靠ddl来压迫自己完成。但是长期的考试比如说考研这种就很难突击，这个软件可以记住我在长期任务里的进度吗

### 问题与诉求

- 短期考试或工作可以依靠截止日期的压力完成，长期任务更难持续推进。
- 考研等长期目标难以依靠临近截止日期时突击完成。
- 希望软件能够长期保存任务进度，方便后续接续推进。

## 3. 工作难以启动，开始后难以停下

### 用户原话

> 每天上班都很难开始工作，一旦开始工作就会坐在那里，不吃不喝坐12个小时

### 问题与诉求

- 每天开始工作存在明显困难。
- 开始后容易持续投入，难以停下，用户描述会连续坐着工作十二小时，期间不吃不喝。
- 需要进一步关注工作启动、暂停与切换，以及工作期间的吃饭、喝水和休息支持。
